Contact details (name, status, advisor, phone, work email/phone, address, gender, household, tags) sync both ways with the SharePoint Contacts list. Editing a field here pushes it to SharePoint, and an edit made directly in SharePoint flows back here — whichever edit happened most recently wins, so an older edit on either side can be silently overwritten if both changed before the next sync.

Import contacts

A .csv file. Export from Excel or Google Sheets with File → Save As / Download → CSV. Only the Name column is required; a person also needs an Email, since that is what identifies them.

Columns recognised (in any order, any capitalisation): Type (Person/Family/Company — defaults to Person), Name, Email, Phone, Status, Household, Household Type, Role, Advisor, Tags, Address, Preferred Name, Work Email, Work Phone. Anything else is ignored.
