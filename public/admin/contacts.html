Contact details (name, status, advisor, phone, work email/phone, address, gender, household, tags) sync both ways with the SharePoint Contacts list. Editing a field here pushes it to SharePoint, and an edit made directly in SharePoint flows back here — whichever edit happened most recently wins, so an older edit on either side can be silently overwritten if both changed before the next sync.
